# Geek Season — frontend

Сайт для подготовки к ЕГЭ по информатике (React + Vite).
Данные берёт у [backend](https://github.com/Geek-Season/backend).

Сейчас есть две страницы:

| Адрес | Страница |
|---|---|
| `/tasks` | Сетка номеров ЕГЭ с поиском |
| `/tasks/17` | Прототипы номера: фильтры по источнику и «решённые / нерешённые», сортировка, проверка ответа |
| `/login` | Вход через Telegram: QR-код или 6-значный код из бота |
| `/profile` | Профиль и статистика: решено, точность, серия, график за 14 дней, «что повторить», прогресс по номерам, достижения |
| `/exam` | Пробник: старт, таймер, автосохранение ответов, завершение |
| `/exam/12` | Результат пробника и разбор |
| `/rating` | Рейтинг за неделю и за всё время |
| `/admin` | Редактор банка задач — только для администратора |

## Запуск

Нужен [Node.js](https://nodejs.org) версии 20 или новее (кнопка «LTS»).

1. Запусти backend (см. его README) — он должен отвечать на <http://127.0.0.1:8000/docs>.
2. В папке этого проекта выполни:

```bash
npm install      # один раз: скачать библиотеки в папку node_modules
npm run dev      # запустить сайт
```

3. Открой <http://127.0.0.1:5173>.

Сайт перезагружается сам при сохранении файла. Остановка — `Ctrl+C`.

## Как сайт общается с backend

Сайт отправляет запросы на `/api/...`, а Vite пересылает их backend'у без `/api`
(настройка `proxy` в `vite.config.js`):

```
браузер → /api/numbers → Vite (5173) → http://127.0.0.1:8000/numbers → backend
```

Если backend на другом адресе: `BACKEND_URL=http://адрес:порт npm run dev`.

## Как устроен код

```
src/
├── main.jsx                  точка входа: адреса страниц (маршруты)
├── api.js                    ВСЕ запросы к backend — только здесь
├── auth.jsx                  кто вошёл: токен в localStorage, useAuth()
├── styles.css                оформление; цвета — в переменных в начале файла
├── components/
│   ├── Layout.jsx            шапка с меню + место для страницы
│   ├── TaskCard.jsx          карточка задачи: условие, ответ, проверка, «решена»
│   └── ActivityChart.jsx     столбики «ответов за день» с подсказкой
└── pages/
    ├── NumbersPage.jsx       страница «Задания» (сетка номеров)
    ├── NumberTasksPage.jsx   страница прототипов номера
    ├── LoginPage.jsx         вход: QR (опрос статуса каждые 2 с) и код
    ├── ProfilePage.jsx       профиль и статистика
    ├── ExamPage.jsx          пробник: старт и решение (таймер, автосохранение)
    ├── ExamResultPage.jsx    результат и разбор
    ├── RatingPage.jsx        рейтинг
    └── AdminPage.jsx         редактор задач (админ)
    └── PlaceholderPage.jsx   заглушка для разделов, которых ещё нет
```

Путь клика «Проверить»: `TaskCard.jsx` → функция `checkAnswer` из `api.js` →
`POST /api/tasks/{id}/check` → backend → ответ → карточка показывает «Верно» или «Неверно».
